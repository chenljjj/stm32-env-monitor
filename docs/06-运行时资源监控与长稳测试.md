# 运行时资源监控与长稳测试

本测试用于验证 STM32 FreeRTOS 版本在持续采集、显示、串口通信和 MQTT 上云同时运行时的资源边界。它不记录 Wi-Fi、Broker、用户名、密码或证书内容。

## 1. 测试前提

- STM32 已烧录 FreeRTOS 资源监控版本，USART2 日志为 115200-8-N-1。
- AHT20、BH1750、SSD1306、ESP32 均正常连接。
- ESP32 已成功连接网络与 MQTT，MQTTX 已订阅遥测主题。

## 2. 观察指标

每 60 个样本会出现一行 `rtos` 资源日志。至少记录：

- `heap` 与 `min`：确认 FreeRTOS 堆未耗尽；
- 四个任务的 `stack` 最小剩余栈：确认没有接近 0；
- `peak` 与 `qdrop`：确认消息队列未长期堆积或丢弃；
- 常规样本行中的 `ackerr`、`retry`、`timeout`、`drop`、网络状态；
- MQTTX 是否持续收到顺序递增的环境遥测。

## 3. 30 分钟基线测试

1. 同时启动 STM32、ESP32 与 MQTTX 订阅。
2. 在串口终端保存日志，记录启动时间。
3. 连续运行至少 30 分钟，期间可遮挡 BH1750 或靠近 AHT20，确认数据仍会变化。
4. 每分钟记录一行资源日志；结束时保存末尾样本与 MQTTX 截图。

通过标准：

- 采样序号持续递增，传感器有效标志正常；
- OLED 正常刷新，`ackerr=0`，无异常重传或超时；
- `min>0`、所有 `stack>0`、`qdrop=0/0`；
- 正常网络下 `peak` 不应长期保持在队列容量 3；
- MQTTX 持续收到真实遥测。

### 3.1 已完成的短时基线

已在真实 AHT20、BH1750、SSD1306、ESP32 与 MQTTX 同时工作的条件下连续运行约 65 秒。稳定阶段的资源日志为：

```text
rtos heap=3344 min=2720 stack=1140/896/864/644 q=1/0 peak=1/1 qdrop=0/0
```

对应期间传感器有效、`ackerr=0`、`retry=0`、`timeout=0`、`drop=0`，ESP32 侧 MQTT 发布与 PUBACK 统计持续增长。该结果说明当前任务栈、堆和队列在短时端到端运行中存在余量，但**不能替代 30 分钟长稳结论**。

首个资源样本曾记录链路任务栈为 0，原因是资源日志执行时任务句柄尚未初始化完成；后续样本读数为 864 字节。记录正式长稳数据时应跳过这一启动瞬间，并确认后续所有任务栈高水位均大于 0。

### 3.2 三端在线长稳记录（2026-08-27）

使用上位机导出的 CSV 对 STM32、ESP32 与 MQTT 三端日志进行同序号关联。真实设备从 `sample=8` 连续到 `16075`，三端各有 16068 条记录，序号无缺口；ESP32 `uptime_ms` 的 16067 个相邻差分全部为 1000 ms，覆盖 4 小时 27 分 47 秒。

| 指标 | 结果 |
| --- | --- |
| 传感器与数据有效性 | AHT20、BH1750 均有效；通信/数据错误均为 0；16068 条 MQTT JSON 均可解析。 |
| UART 与网络 | `rxerr=0`、`txerr=0`、`ackerr=0`、`retry=0`、`timeout=0`、`drop=0`、`qdrop=0/0`；全程 `net=WM`，`wd=0 md=0`。 |
| ESP32 发布队列 | 末次为 `queue=0`、`overflow=0`、`puberr=0`、`abandoned=0`，`submitted=accepted=puback=16072`。 |
| FreeRTOS 资源日志 | 267 条均可解析，`heap=3344`、`min=2720` 始终不变；任务栈最低剩余值为采集/显示/链路/健康=`1140/848/864/616` 字节，均大于 0。 |

CSV 的到达时间可能受到串口缓冲和上位机调度影响，因此不以相邻文本日志的墙钟间隔判定调度失败，而以 ESP32 单调运行时间和连续采样号作为节拍证据。本记录已满足 30 分钟基线；下一阶段应扩展至 24 小时，并在断网、队列满、ACK 丢失、ESP32 异常断电场景下记录相同资源指标。

## 4. 推荐故障注入顺序

完成基线后，可依次关闭手机热点、复位 ESP32、恢复网络，观察 STM32 采样和显示是否持续，ESP32 是否重新上线并补发队列数据。队列满与 ACK 丢失测试需要谨慎控制持续时间，避免把异常数据当成正常性能结论。
